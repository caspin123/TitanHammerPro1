# Prime Host — خطة تصميم فيديو الموشن (SaaS Promo)

> فيديو إعلاني احترافي لشركة الاستضافة **برايم هوست | PRIME HOST**
> المدة: **30 ثانية** · الدقة: **1920×1080 @ 30fps** · الصيغة: MP4 (H.264) مع موسيقى/مؤثرات صوتية مولَّدة

---

## 1. الهوية البصرية (Design System)

تم توليد النظام التصميمي باستخدام مهارة **ui-ux-pro-max** (`--design-system --motion 9`):

| العنصر | القرار |
|---|---|
| النمط الأساسي | **Liquid Glass** — زجاج سائل شفاف، ضبابية ديناميكية، انعكاسات لامعة (Specular)، حواف مضيئة |
| النمط المساند | **Claymorphism** — أيقونات وأزرار طينية ثلاثية الأبعاد ناعمة (ظلال داخلية مزدوجة + ظل خارجي عميق) |
| النمط الحركي | Complex choreography — `expo.inOut` للانتقالات (500–800ms)، `expo.out` للدخول، `back.out` للأيقونات |
| الخلفية | أسود دافئ `#07060A` مع Mesh Gradient ذهبي/برونزي متحرك يعطي الزجاج شيئاً "يكسره" |
| اللون الأساسي | ذهبي معدني مأخوذ من الشعار: `#FFE8A3 → #F5D06F → #C8922E → #8A5A12` |
| الخطوط | **Cairo** (عربي 400–900) · **Cinzel** (شعار PRIME HOST الملكي) · **Sora** (أرقام وعناوين إنجليزية) |
| الأيقونات | SVG بأسلوب Lucide (لا إيموجي) داخل مربعات Clay ذهبية |
| تجنّب | الحركات السريعة الرخيصة، الألوان المشبعة الصارخة، النص منخفض التباين فوق الزجاج |

### وصفة الزجاج السائل (Liquid Glass)
1. `backdrop-filter: blur(26px) saturate(170%)` فوق خلفية Mesh متحركة.
2. تدرج أبيض شفاف 135° (12% → 3%).
3. حافة مضيئة بتدرج (Mask-composite) — أبيض من الأعلى-اليسار وذهبي من الأسفل-اليمين.
4. انعكاس لامع (Specular blob) + **Sheen** يمر عبر البطاقة في لحظات محددة.
5. ظل خارجي عميق `0 40px 90px rgba(0,0,0,.55)` لإحساس الطفو.

### وصفة Clay
`inset 8px 10px 18px` ضوء كريمي + `inset -8px -10px 18px` ظل برونزي + ظل خارجي ناعم كبير، مع تدرج ذهبي 145°.

## 3. التصميم الصوتي (مولَّد برمجياً — بدون حقوق)
- **Pad** سينمائي (A minor) يتصاعد تدريجياً.
- **Riser** (ضوضاء مفلترة صاعدة) قبل كل انتقال.
- **Impact** منخفض عند سقوط التاج وعند الخاتمة.
- **Pulse** إيقاعي خفيف (100 BPM) في مشاهد المميزات.
- **Shimmer** (أجراس عالية) مع لمعان الشعار.

---

## 4. التقنية
- مشهد HTML/CSS واحد (1920×1080) + **GSAP Timeline** متوقف (paused) يتم التحكم به إطاراً بإطار (`tl.seek(t)`) → نتيجة **حتمية** بلا تقطيع.
- Canvas للجزيئات والشرارات والكرة الأرضية، كلها دوال للزمن `t` فقط.
- **Playwright/Chromium** يلتقط 900 إطار بالتوازي (4 عمال) → **FFmpeg** يرمّزها H.264 (CRF 16) مع الصوت.
- كل النصوص والأسعار في كائن `CONFIG` أعلى `index.html` لسهولة التعديل.

## 5. ملاحظة
الأسعار والأرقام (99.99%، عدد مراكز البيانات…) **أمثلة توضيحية** — عدّلها في `CONFIG` لتطابق عروضكم الحقيقية ثم أعد التصيير بـ `./build.sh`.
